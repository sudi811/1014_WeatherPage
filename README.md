# 🗺️ 台灣區域天氣預報互動式地圖

### 🔗 網頁即時預覽 (Live App)
👉 **[https://1014weatherpage-qwymqshg45fatz9vprv8ap.streamlit.app/](https://1014weatherpage-qwymqshg45fatz9vprv8ap.streamlit.app/)**
---

這是一個使用 **Streamlit**、**SQLite** 以及 **Folium (Leaflet)** 地圖技術打造的台灣一週氣溫預報互動式網頁 App。本專案資料介接自中央氣象署 (CWA) 開放資料 API。
